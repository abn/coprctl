# Quick start

This page will grow into a guided first-use walkthrough as the CLI matures:
installing the binary, configuring a profile, authenticating, and running the
first project and build commands.

Until the M0 skeleton lands, the authoritative design and examples live in the
working specification. The examples there show the intended command surface,
including standing up a project and wiring a GitHub webhook.
